OrcAI is a self-hostable platform for governed, retrieval-backed AI assistants. It originated in the [SokratesT project](https://github.com/SokratesT/sokratest) and still supports learning workflows where instructors curate material and students interact with a grounded AI tutor. OrcAI has since moved beyond a fixed instructor–student model: individuals and groups can build specialised knowledge bases and assistants for their own domains.

<Callout title="Documentation status" type="info">
	The project is still in active development. Treat the current documentation as an implementation-oriented headstart rather than a complete product manual.
</Callout>

## What OrcAI Does

OrcAI combines content ingestion, semantic search, and chat:

1. Workspace members upload source material.
2. Background workers process files and extract usable text or image descriptions.
3. Processed content is stored in S3-compatible object storage.
4. Extracted content is indexed in Qdrant for retrieval.
5. Users chat with the platform.
6. Relevant context is retrieved and sent to the configured AI model endpoint.

## Core Areas

- Home (`/app`): the start page after sign-in, with a Use tab for asking questions and a Manage tab with an overview of the organisation.
- Chat (`/app/chat`): AI conversations, optionally started from a bot.
- Library (`/app/hub`): reusable resources, with Bots, Behaviour, Repositories and Assets.
- OrcAI Assistant (`/app/assistant`): the built-in helper for questions about your work and about OrcAI.
- Access control: organisations, roles, groups, invitations and resource sharing.
- Administration: Users, Groups, Quotas, Providers, Models and Organisation for the active organisation, shown to members whose role allows them.
- Instance management (`/instance`): health, organisations and accounts across the whole instance, for instance administrators.

## Getting Access

Access to the managed service of OrcAI is currently only available via direct invites from users already on the platform. If you want to create your own organisation (isolated workspace) to invite users yourself, contact us at [sokratest@hochschule-rhein-waal.de](mailto:sokratest@hochschule-rhein-waal.de)
