OrcAI lets organisations build bots that answer from their own material and cite their sources. It started in teaching and learning and also serves research groups and specialist teams. Members upload files, OrcAI prepares them as assets, and bots search those assets to answer questions.

OrcAI is in beta and changes often.

## Main capabilities

- Chats with bots that answer from their repositories and cite the passages they used
- Web search with cited pages, questions and quizzes the bot grades, and Generative UI checklists, reviews and tables
- The OrcAI Assistant, which answers questions about OrcAI and sets up bots, behaviours and repositories for you
- A Library of assets, behaviours and repositories that any number of bots reuse, with metadata the utility model suggests
- The Catalogue, where organisations list bots and blocks for everyone on the instance
- Roles, groups, invitations and sharing on each bot, block and asset
- Providers, models, quota pools and analytics for admins
- [Self-hosting](/docs/self-hosting) with Docker Compose, PostgreSQL, Valkey, S3-compatible storage, Qdrant and SpiceDB
