The OrcAI repository is a Bun workspace with applications under `apps/*` and shared packages under `packages/*`.

## Main Applications

- `apps/app`: main OrcAI application.
- `apps/workers`: background worker process.
- `apps/web`: website and documentation service.

## Recommended Workflow

Run `bun install --frozen-lockfile`, then `bun run stack up`. This starts an isolated Docker Compose project for the checkout, writes a gitignored `.env` with per-worktree ports, applies migrations, initializes MinIO buckets, and applies the SpiceDB schema. Start the app with `bun run stack dev` or everything with `bun run stack dev --all`. Several checkouts or worktrees can run at the same time without port conflicts.

The repository also includes a VS Code devcontainer that provides the same infrastructure inside Compose. For details on either path, see the [README](https://github.com/LarsLrn/orcai#development-workflows) and the [Commands](/docs/development/commands) page.
