---
title: Configuration
description: Required and optional environment variables for OrcAI.
---

Runtime configuration is loaded across app and package config modules. `.env.example` is the current baseline for self-hosted environments. Every value comes from the container environment and applies when the container restarts, so one image serves any deployment. Build args only carry image identity, never deployment values.

When SMTP is not configured, emails are not delivered. The local-testing fallback logs complete rendered messages, including password-reset, verification, and invitation links. Do not use log-only mode in production, and treat any captured output as credential-bearing sensitive data.

<Callout title="Self-hosting scope" type="info">
	Custom embedding model definitions are supported only in self-hosted deployments. For managed/shared deployments, these are instance-level settings controlled by the hosting operator.
</Callout>

Primary config modules:

- `packages/ai/src/config.ts`
- `packages/db/src/config.ts`
- `packages/notifications/src/config.ts`
- `packages/qdrant/src/config.ts`
- `packages/s3/src/server/config.ts`
- `packages/spice-db/src/config.ts`
- `packages/valkey/src/config.ts`
- `apps/app/src/lib/effect/services/config.ts`

## Public URLs

| Variable | Required | Notes |
| --- | --- | --- |
| `BETTER_AUTH_URL` | Yes | The app's public origin, used for auth callbacks and links in emails. Passkeys are bound to its host name, so changing the domain invalidates every registered passkey; users then sign in with their password and add them again. |
| `WEB_URL` | No | Public docs site base URL used in the app dashboard and in the OrcAI Assistant's docs links. It is also where the Assistant reads the docs unless `WEB_INTERNAL_URL` is set. Without it the Assistant cannot read the docs. |
| `WEB_INTERNAL_URL` | No | Docs site origin the app server fetches for the Assistant. Defaults to `WEB_URL`. Docker Compose sets `http://web:3001`. |

## Authentication And Encryption

| Variable | Required | Notes |
| --- | --- | --- |
| `BETTER_AUTH_SECRET` | Yes | Better Auth signing secret. |
| `BETTER_AUTH_RATE_LIMIT` | No | `false` turns off Better Auth's rate limiting, which is on in production by default. It keys clients by `X-Forwarded-For`; requests without exactly one address in it share one limit. |
| `ENCRYPTION_KEY` | Yes | 32 to 64 character application encryption key. Provider API keys are stored encrypted with it, so the app and the workers need the same value. |
| `TWO_FACTOR_REQUIRED` | No | Who must use two-factor authentication: `none` (default), `admins` (instance admins) or `all`. A covered user without it is sent to set it up before using the app. |

## Database And Cache

| Variable | Required | Notes |
| --- | --- | --- |
| `POSTGRES_USER` | Yes | PostgreSQL user. |
| `POSTGRES_PASSWORD` | Yes | PostgreSQL password. |
| `POSTGRES_HOST` | Yes | PostgreSQL host. |
| `POSTGRES_PORT` | Yes | PostgreSQL port. |
| `POSTGRES_DB` | Yes | PostgreSQL database name. |
| `POSTGRES_POOL_MAX` | No | The most connections each pool opens, default `10`. The app runs three pools (queries, Better Auth, pg-boss) and the workers two (queries, pg-boss); keep the total for all processes below PostgreSQL's `max_connections` (100 by default). |
| `VALKEY_URL` | Yes | Valkey connection URL. |
| `WORKER_POLLING_INTERVAL_SECONDS` | No | Replaces how often every background worker polls its queue, at least `0.5`. Unset, each worker keeps its own interval of 2 to 30 seconds. |

## Object Storage

| Variable | Required | Notes |
| --- | --- | --- |
| `S3_ENDPOINT` | Yes | Internal S3-compatible endpoint. |
| `S3_PUBLIC_ENDPOINT` | No | Public endpoint used for presigned URLs. |
| `S3_REGION` | No | Defaults to `eu-central-1`. |
| `S3_ACCESS_KEY` | Yes | S3 access key. With the bundled SeaweedFS, it also sets the server's admin key. |
| `S3_SECRET_KEY` | Yes | S3 secret key. With the bundled SeaweedFS, it also sets the server's admin secret. |

## AI And Retrieval

| Variable | Required | Notes |
| --- | --- | --- |
| `OPENAI_COMPATIBLE_BASE_URL` | Yes | Base URL for an OpenAI-compatible API. |
| `OPENAI_COMPATIBLE_API_KEY` | Yes | API key for the model endpoint. |
| `EMBEDDING_MODEL` | Yes | Embedding model exposed by the endpoint. |
| `EMBEDDING_DIMENSIONS` | Yes | Positive integer vector size for the embedding model and Qdrant collection. |
| `KREUZBERG_OCR_LANGUAGE` | No | OCR languages for asset preparation. Defaults to `eng` in host-oriented code and `eng+deu` in Compose examples. |

<Callout title="Do not mix embeddings" type="warn">
	Changing `EMBEDDING_MODEL` or `EMBEDDING_DIMENSIONS` after assets have already been indexed is not supported. Recreate the Qdrant collection and prepare assets again instead of mixing embeddings.
</Callout>

## SpiceDB

| Variable | Required | Notes |

| `SPICEDB_ENDPOINT` | Yes | SpiceDB gRPC endpoint. |
| `SPICEDB_TOKEN` | Yes | Token used by the app. |
| `SPICEDB_SECURITY` | No | Transport mode for SpiceDB client. Defaults to `insecure-plaintext`. Valid values: `secure`, `insecure-localhost`, `insecure-plaintext`. |

## Email

Email delivery stays in log-only mode unless SMTP is configured.

| Variable | Required | Notes |
| --- | --- | --- |
| `SMTP_HOST` | No | Must be set with `SMTP_FROM` to enable SMTP. |
| `SMTP_PORT` | No | Defaults to `587` when SMTP mode is enabled and no port is set. |
| `SMTP_USERNAME` | No | Must be paired with `SMTP_PASSWORD` if used. |
| `SMTP_PASSWORD` | No | Must be paired with `SMTP_USERNAME` if used. |
| `SMTP_SECURE` | No | If unset, derived from port (`true` for 465, otherwise `false`). |
| `SMTP_TLS_REJECT_UNAUTHORIZED` | No | Defaults to `true`. |
| `SMTP_FROM` | No | Must be set with `SMTP_HOST` to enable SMTP. |
| `SMTP_FROM_NAME` | No | Defaults to `OrcAI Team`. |
